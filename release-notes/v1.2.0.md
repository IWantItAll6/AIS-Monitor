## Fixes
- **Fixed a crash when sorting the vessel list.** Sorting by Name (or by Seen in Live mode) could crash the app. This also fixes sort-by-name and pin-to-top.
- **Light mode now actually shows as light** on newer Qt versions, which had been ignoring it and following the OS dark theme.
- **RSSI Export is only enabled when the selected vessel has RSSI history.**

## Improvements
- **Much faster scrubbing on long logs.** Scrubbing now only replays the last Track Length / Vessel Timeout window instead of the whole file from the start. On a ~2-hour log, a scrub near the end went from ~94s to ~7s.
- **Large-file scrub warning.** When a file is loaded, the app warns you if your Track Length / Vessel Timeout settings will make scrubbing slow for that file.

## New features
- **Daylight Map Colors** (Preferences → Map): a bright, high-contrast map palette that's easier to read in direct sunlight. It's separate from the app's Dark/Light theme.
- **Single-vessel track export** from File Analysis: Show Track, and export the track as a PNG.
- **RSSI History export.**
- **File Analysis splits MMSI and vessel name** into separate columns.
- **Copyable vessel details.** You can select and copy any value in the Selected Vessel panel (position, MMSI, name, etc.).
- **Help updated** to cover all of the above.

## Known issues
- The Windows zip wraps everything in an extra `AISMonitor/` folder, so open that folder to find the exe. This is fixed for the next release.
