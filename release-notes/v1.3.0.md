## New features
- **Range Limit** (Preferences → Map): hides vessels beyond a set distance from the map and the vessel list. It steps in 10s, defaults to 60 NM, and can be set to **Off**. The list shows how many are hidden, e.g. "Targets (68 of 107)". Pinned vessels are always shown, nothing is hidden until there's a GPS fix, and the limit follows your distance unit. It only affects the display: recordings, network broadcast and File Analysis still include every vessel.

## Fixes
- **Faster replay speeds now actually play faster.** On busy log files, 2x and above used to run close to real time because map redraw time was never subtracted from each wait. Playback now keeps time against a real clock, so on the trial log 2x measures 1.99x and 10x measures 9.99x (previously 1.54x and 3.09x). Speed changes also take effect immediately.
- **Windows release zip:** the exe is now at the top level of the zip instead of inside an extra `AISMonitor/` folder.

## Upgrade note
- The Range Limit is on by default at 60 NM, so vessels further away than that will disappear after upgrading. Set it to Off in Preferences → Map to show everything, as before.
