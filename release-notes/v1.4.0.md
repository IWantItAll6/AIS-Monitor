## New features
- **SAR aircraft** (AIS message 9) are now drawn as a **plane** pointing along their course, instead of a vessel triangle. Their altitude can be shown with the new optional **Altitude** detail field (View → Vessel Detail Fields), and it's included in the target-list CSV export. Aircraft are also recognised by their 111 MMSI prefix, so a static-data report doesn't turn them back into a vessel marker.
- **Message statistics** (View → Message Statistics...): a window you can leave open beside the map. It shows the total messages received, the rate in messages per minute, how many Class A, Class B, base station, SAR aircraft and AtoN stations have been heard, and a breakdown by message type. **View → Show Message Rate in Status Bar** keeps the rate always visible, which makes a receiver or antenna going quiet easy to spot. Per vessel, there are optional **Msgs** / **Msg/min** list columns and **Messages** / **Message Rate** detail fields. During replay, rates use the file's own timestamps, so they show what was received at the time rather than the playback speed.
- **Course/speed prediction line** (Preferences → Map, off by default): a dashed, semi-transparent line ahead of each moving vessel, ending in a small circle at where it will be after the set time (default 10 minutes) at its current speed and course. It's thinner and dashed so it can't be confused with the solid track behind. SAR aircraft get a line a tenth as long, so it doesn't swing wildly while they turn. Vessel labels move beside the vessel while the line is on, so they don't sit on it.
- **Stationary vessels: Show normally / Dim / Hide** (Preferences → Map, default Show normally). Declutters the map by fading or hiding anything sitting still: ships slower than **Stationary Below** (default 0.5 kn) or reporting At Anchor / Moored, plus Aids to Navigation and base stations. **Dim** fades the marker, label and track; **Hide** removes them from the map but not the target list. Pinned vessels, your own ship, SART/MOB/EPIRB beacons and SAR aircraft are never dimmed or hidden. Stationary ships don't get a prediction line either.
- The bundled **sample replay log** now includes a SAR aircraft flying a search orbit and a slowly drifting vessel, to show off the features above.

## Fixes
- **SAR aircraft speeds were being discarded.** Message 9 reports speed in whole knots up to 1022, but the parser applied the ship "not available" value (102.3 kn) to it, so almost every real aircraft speed was dropped. Vessel Uptime and File Analysis now also use the correct 10-second reporting interval for aircraft.
- Help said a pinned distress beacon turns "pastel red"; it actually turns magenta. The text is corrected.
