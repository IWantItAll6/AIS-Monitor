# resources/

Real captured AIS/GNSS/PSMT field-test log files go here, in the same
`[YYYY-MM-DD HH:MM:SS.ffffff] <sentence>` format the app's replay mode
and live-session recording feature both use.

These files are private and aren't committed to the repository (see
`.gitignore`) — only the maintainer's own captures, never shared publicly.
`tests/test_replay_regression.py` looks for two specific filenames here
(`field_log_1.txt`, `field_log_2.log`) and skips those tests gracefully if
they're not present, so the suite still runs cleanly for anyone else
cloning the repo.

If you have your own AIS/GNSS capture in the same format, drop it here
(any filename) and use **File > Open Replay...** to load it in the app.

## sample_replay.log

This one *is* committed — it's fully synthetic (generated by
`scripts/generate_sample_log.py`), with made-up vessel names, MMSIs, and
positions, none derived from real captures. It gives anyone cloning the
repo a working replay file and a public-safe fixture for
`tests/test_sample_replay.py`, without needing a real receiver or the
private field logs above. Re-run the generator script to regenerate it
after changing the scenario.
